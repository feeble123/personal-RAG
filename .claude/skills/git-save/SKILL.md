# Git 存档并推送

帮用户把当前项目的改动保存到 git 并推送到远程服务器。

## 步骤

1. **查看改动**：运行 `git status --short`，了解有哪些文件被修改了。

2. **暂存所有改动**：运行 `git add -A`。

3. **提交**：
   - 如果用户提供了存档说明（例如 `/git-save 修复了账单页 bug`），就用它作为提交信息。
   - 否则，根据改动文件自动生成一个简短说明，或者用当前日期时间，例如：`存档 2026-08-02 10:35`。
   - 运行 `git commit -m "<提交信息>"`。

4. **推送到远程**：运行 `git push`。

5. **告诉用户结果**：报告提交了几条记录、推送是否成功。如果推送失败（比如远程地址没配、网络不通），把错误告诉用户。

## 备注

- 如果 `git push` 提示没有远程仓库，先运行 `git remote -v` 查看；没有的话告诉用户需要先配置远程地址。
- 如果提交时发现没有需要保存的改动（`nothing to commit`），直接告诉用户"当前没有改动需要存档"。
