# Excel 导入样例

配合「本体管理」里的三处导入功能使用。每个文件第二张工作表写着用途和字段说明（导入只读第一张表）。

| 文件 | 用在哪 | 怎么试 |
|---|---|---|
| `01_实例导入_水闸.xlsx` | 实例 tab → **Excel 批量导入** | 类型选「水闸」，先点「先预演」看对上的列和报错行，再「确认导入」（前 3 行会建出来） |
| `02_属性生成_表头示例.xlsx` | 本体结构 → 展开实体 → **从 Excel 表头生成** | 随便选一个实体类型，看它按样例值猜出的类型，改完字段名再确认 |
| `03_参数表导入_模板.xlsx` | 参数表导入 tab（**只能在「调参本体」这类含参数类型的库里用**） | 就是参数先验表格式。库里那 13 个参数已经导入过，所以预演会显示「无变化 13」——这是正常的，不是失败 |
| `04_参数表导入_新增2个参数.xlsx` | 同上 | 比模板多了 `lag_t` / `gw_k` 两个新参数，预演应显示「**会新增 2**」，正式导入后到实例页能看到 |

## 关于 `01_实例导入_水闸.xlsx`

表头用了**属性标识**（`design_flow`）。也可以写属性的**中文说明**（如「设计流量」），程序两种都认；都对不上的列会被跳过并列出来，不会瞎猜。

最后一行 `坏样例闸` 是故意的：`design_flow` 写了「很大」，导入时会报「不是数字」并跳过该行——用来确认错误提示长什么样。

## 参数表导入的两个常见困惑

1. **「预演出来全是 0」** —— 现在预演会明确告诉你「会新增 N / 会更新 N / 无变化 N」。
   如果三个都是 0，说明表里一行都没解析出来（多半是表头不对）。
2. **「导入后没变化」** —— 如果显示「无变化 13」，表示这 13 个参数库里已经有了且内容一致，
   导入本身是成功的，只是没有需要写的东西。想看真效果用 `04_..._新增2个参数.xlsx`。
3. **当前库不对** —— 参数表只认 `Parameter` 类型。在「水闸调度本体」里点导入，会直接提示
   「当前图谱库没有「参数」类型」，切到「调参本体」即可。
